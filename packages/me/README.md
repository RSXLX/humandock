# ME integration boundary

This package contains independent read-only ME identity and RPC adapters, exact EIP-712 contract helpers, and generated ABIs. It does not import the upstream SDK, derive a DID from a wallet, read wallet seeds, issue identity attestations, or send ME transactions.

## Explicit configuration

Run `npm run me:preflight` after setting the following deliberately unpopulated network values:

| Variable | Meaning |
| --- | --- |
| `ME_NETWORK` | `local`, `me-testnet`, or `me-mainnet` |
| `ME_EVM_RPC_URL` | Verified endpoint; HTTPS unless local loopback |
| `ME_EVM_CHAIN_ID` | Expected positive decimal EVM chain ID |
| `ME_NATIVE_SYMBOL` | Confirmed native currency symbol |
| `ME_BANK_DENOM` | Confirmed Cosmos bank denomination |
| `ME_BANK_DECIMALS` | Confirmed bank decimal precision, 0–18 |
| `ME_QUANTUM_WEI` | Decimal integer, `10^(18 - bankDecimals)` for this adapter |
| `ME_COSMOS_REST_URL` | Optional for RPC probe; required for identity reads |
| `ME_MIN_KYC_LEVEL` | Required for admission, 1–5 after official mapping confirmation |
| `ME_ID_POLICY_REFERENCE` | Recorded basis for the configured identity level |

No default chain ID, endpoint, denomination or quantum silently enables a network. RPC preflight queries `eth_chainId`, `web3_clientVersion` and `eth_getBlockByNumber`, verifies the configured chain ID, and reports a block/hash. It always returns `liveWritesEnabled: false`, `unitsVerifiedOnLiveChain: false`, and `identityVerified: false`; RPC reachability does not satisfy these independent gates.

The HTTPS policy does not alter the upstream HTTP address to an invented HTTPS URL. The separately authorized observation in `observations/testnet-readonly-probe.json` recorded one successful block-height response from the SDK's HTTP test endpoint and two five-second chain-ID timeouts. It is partial reachability evidence, not proof of chain ID, native units, contract deployment, or mainnet functionality.

## Official source evidence

The SDK default branch was rechecked against immutable revision [`a56f3e936396de8689c2fc8667ad7306765eee9f`](https://github.com/openmetaearth/meta-earth-js-sdk/tree/a56f3e936396de8689c2fc8667ad7306765eee9f). Query paths are verified in [`src/api/identity.ts`](https://github.com/openmetaearth/meta-earth-js-sdk/blob/a56f3e936396de8689c2fc8667ad7306765eee9f/src/api/identity.ts):

- `/metaearth/did/did?address=...`
- `/metaearth/did/didInfo?did=...`
- `/metaearth/kyc/QuerySubAccountDidResponse?sub_account=...`

Known protobuf vocabulary is `DID_STATUS_INACTIVE/ACTIVE` or numeric 0/1, and `KYC_LEVEL_NONE/ONE/TWO/THREE/FOUR/FIVE` or numeric 0–5. Unknown response shapes, states and levels fail closed. A wallet-admission read cross-checks the subaccount record against the main-address record, active status and explicitly configured KYC threshold. It requires the caller to have verified a separate wallet-control challenge first. The adapter makes no claim that an identity query proves current liveness, English ability, honesty or lack of AI assistance. Raw DID results are private server data and must not be placed in public logs, public receipts or onchain storage.

ME Hub revision [`1e9eff8a5feae166fe9d72ad4bcc904622b078a1`](https://github.com/openmetaearth/me-hub/blob/1e9eff8a5feae166fe9d72ad4bcc904622b078a1/go.mod) pins Ethermint [`08a9eaaee040`](https://github.com/openmetaearth/ethermint/blob/08a9eaaee040/x/evm/keeper/statedb.go), whose balance path distinguishes EVM 18 decimals and bank 8 decimals (`q=10^10`). This source evidence is not an attestation of the running network. The source test defaults remain chain 400 / HTTP `118.175.0.249:8545`; mainnet EVM fields are not populated in that SDK configuration, and its README qualifies live mainnet write verification.

## Integration contract

`src/contracts.ts` is the shared signed-data definition. Its salted commitment helper matches the domain package exactly:

```text
taskCommitment     = keccak256(abi.encode(keccak256('HumanDock/SOURCE/v1'), manifestHash, independentSourceSalt))
deliveryCommitment = keccak256(abi.encode(keccak256('HumanDock/FINAL/v1'), manifestHash, independentFinalSalt))
```

Manifest hashes and both 256-bit random salts stay in authorized private storage. `src/generated-abis.ts` is generated by contract compilation. Use `bigint` for EVM wei, decimal strings across JSON boundaries, and reject unrepresentable conversions rather than truncate them. The root application deliberately keeps demo balances separate from a future live ME ledger.
